# 中英混说辅助

## 为什么要做

真实用户练口语时，经常不是完全不会，而是说到一半卡住。

典型表达：

```text
我负责用户调研 and roadmap planning，然后和设计工程一起推进上线。
```

如果产品要求用户必须全英文，很多人会直接放弃。中英混说辅助的目标是降低开口门槛。

## 产品逻辑

1. 用户可以输入中文、英文或中英混说。
2. 系统检测是否包含中文。
3. 如果包含中文，先整理成自然英文。
4. 页面展示原始表达和整理后的英文。
5. AI 考官基于整理后的英文继续追问和反馈。

## 用户价值

- 用户不需要一开始就完美英文。
- 用户能看到自己的中文想法如何变成职场英文。
- 练习不中断，心理压力更低。
- 更适合中国职场人的真实学习路径。

## AI 产品经理视角

这个功能不是简单翻译，而是一个“学习脚手架”：

- 保留原意。
- 降低开口压力。
- 让用户从中文思维过渡到英文表达。
- 同时提供可评估的英文输入，方便后续评分和追问。
