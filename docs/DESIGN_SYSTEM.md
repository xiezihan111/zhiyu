# 职语 Coach 设计系统

## 设计方向

职语 Coach 采用“职场工具感 + 轻量学习氛围”的移动端视觉风格。

- 专业，但不压迫。
- 清晰，但不冷冰冰。
- 鼓励开口，但不过度游戏化。
- 重点突出练习场景、对话内容和反馈结果。

## 核心配色

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 职业蓝 | `#0369A1` | 主按钮、用户消息、关键选择 |
| 深墨蓝 | `#102A43` | 主要文字、标题 |
| 青蓝 | `#0891B2` | 渐变、进度、互动状态 |
| 成长绿 | `#0F766E` | 英文整理、优势、完成状态 |
| 提醒琥珀 | `#A15C07` | 即时建议、注意事项 |
| 雾蓝背景 | `#F3F7FA` | 页面背景 |
| 白色 | `#FFFFFF` | 内容表面 |
| 边框灰蓝 | `#DCE7EF` | 卡片、输入框、分隔 |

## 组件规则

- 卡片圆角统一为 `16rpx`，减少过度圆润感。
- 主按钮高度不低于 `96rpx`，满足移动端触控需求。
- 小型操作按钮触控高度不低于 `60rpx`。
- 页面间距采用 8px 节奏，对应小程序中的 `16rpx` 倍数。
- 阴影只用于主视觉和需要抬升的内容，普通区域以边框区分。
- 每个页面只保留一个最明确的主操作。

## 语义色

- 蓝色：选择、提交、AI 交互。
- 青绿色：成功、进步、英文整理。
- 琥珀色：建议、提醒、可改进内容。
- 红色：录音中、失败、危险状态。

## 避免

- 紫蓝 AI 模板式渐变。
- 儿童教育式糖果色和膨胀阴影。
- 多层卡片嵌套。
- 仅靠颜色表示状态。
- 小于 44px 的主要触控区域。

设计依据来自 `ui-ux-pro-max` 的移动端触控、可访问性、职场产品配色与简体中文字体建议。
