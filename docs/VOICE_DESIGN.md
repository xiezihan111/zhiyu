# AI 考官声音设计

## 目标声音

职语 Coach 的考官声音不追求播客感或强烈情绪，而是接近标准化英语听力材料：

- 标准美式英语。
- 语速略慢于自然对话。
- 吐字清楚。
- 句子重音自然。
- 从句之间有清楚停顿。
- 情绪稳定、克制、专业。

## 当前实现

真实 AI 模式使用：

```text
gpt-4o-mini-tts
voice: cedar
```

后端通过 `instructions` 控制：

- 口音。
- 语速。
- 停顿。
- 语调。
- 情绪范围。

## 为什么演示模式仍会偏机械

演示模式的本地音频由 Windows 离线系统语音生成，不需要 API Key，但自然度有限。

要听到真正自然的“考试听力播音”效果，需要：

1. 配置 OpenAI API Key。
2. 启动本地后端。
3. 关闭小程序的演示模式。
4. 打开 AI 考官语音。

## 后续可增加

- 标准美式 / 标准英式切换。
- 正常速度 / 慢速学习切换。
- Voice A / Voice B 切换。
- 第一遍正常速度，第二遍慢速重听。
