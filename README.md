# 职语 Coach

面向中国职场人的 AI 英语面试/会议口语陪练 MVP。

这个版本适合两个目标：

- 做 AI 产品经理面试作品集。
- 快速验证“职场英语 AI 陪练”是否有人愿意用。

## 目录

- `miniprogram/`：微信小程序源码，用微信开发者工具导入。
- `server/`：本地 Node.js AI 接口，连接 OpenAI。
- `docs/BEGINNER_GUIDE.md`：小白一步一步操作教程。
- `docs/PRD.md`：产品方案，可直接放进作品集。
- `docs/INTERVIEW_STORY.md`：面试时怎么讲这个项目。
- `docs/APP_ROADMAP.md`：后期从小程序变成 App 的路线图。
- `docs/NAMING.md`：产品命名和品牌方向。
- `docs/MONETIZATION.md`：盈利模式和收费路径。
- `docs/MIXED_LANGUAGE_ASSIST.md`：中英混说辅助设计。
- `docs/VOICE_DESIGN.md`：AI 考官声音与听力播音风格。
- `docs/DESIGN_SYSTEM.md`：职场轻学习视觉系统与配色规范。
- `docs/API_TESTING_GUIDE.md`：接口联调、自动测试和上线检查。
- `docs/MEASUREMENT_PLAN.md`：产品埋点、AI 评测和用户验证指标。
- `docs/RESUME_EVIDENCE.md`：可以写进简历的真实结果与证据边界。

## 第一版功能

- 选择练习场景：英文面试、会议发言、自我介绍。
- 选择岗位：产品经理、程序员、运营、销售。
- AI 面试官/考官连续追问。
- 支持文字回答；支持录音上传到本地后端转文字。
- 每轮回答后给即时反馈。
- 结束后生成评分报告和更自然的英文表达。
- 没有 API Key 时可用演示模式完整跑通。
